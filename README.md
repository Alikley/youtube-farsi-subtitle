# YouTube Farsi Subtitle

یک پروژه متن‌باز برای گرفتن صوت ویدیوهای یوتیوب، تبدیل به متن (Transcribe) با Whisper، ترجمه خودکار و نمایش زیرنویس فارسی در اکستنشن مرورگر.

## ویژگی‌ها

- دانلود صوت از یوتیوب با `yt-dlp`
- تبدیل گفتار به متن با `whisper.cpp`
- ترجمه متن با مدل‌های هوش مصنوعی
- ارائه API برای استفاده اکستنشن
- متن‌باز و قابل توسعه توسط جامعه
